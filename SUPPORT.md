# Support

Thanks for using Roundtable.

If you need help, please choose the right place:

- Bug reports, crashes, or unexpected behavior: [Open a GitHub issue](https://github.com/Just-Me-Media/FreeLLMAPI-Roundtable/issues)
- Questions, usage help, or ideas: [Start a GitHub discussion](https://github.com/Just-Me-Media/FreeLLMAPI-Roundtable/discussions)
- Security vulnerabilities: [Report privately](https://github.com/Just-Me-Media/FreeLLMAPI-Roundtable/security/advisories/new)

Before opening an issue, please check whether your problem is already covered in the README, the release notes, or an existing issue.

If you are reporting a bug, include the following:

- What you expected to happen
- What actually happened
- Steps to reproduce the issue
- Your platform, OS, and Node.js version
- Which model/provider you were using
- Any relevant logs or screenshots

Roundtable is an unofficial companion project for FreeLLMAPI. Support here is for Roundtable issues, not for the upstream FreeLLMAPI project.

If you find the project useful, you can also support development via [Buy Me a Coffee](https://buymeacoffee.com/justmemedia).
