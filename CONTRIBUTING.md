# Contributing to Roundtable

Thanks for your interest in improving Roundtable.

## Getting started

1. Fork the repository.
2. Clone it locally.
3. Install dependencies:

```bash
npm install
```

4. Start the app locally:

```bash
npm start
```

5. If you are testing with local models, make sure one of the supported local endpoints is running, such as Ollama on `127.0.0.1:11434` or LM Studio on `127.0.0.1:1234`.

## Ways to contribute

- Report bugs and reproduction steps
- Suggest features or UX improvements
- Improve documentation
- Submit pull requests with fixes or enhancements

## Before you open a pull request

- Keep changes focused and easy to review
- Update the relevant documentation when behavior changes
- Test the affected workflow if possible
- Follow the existing code style and project structure

## Issue reports

When filing a bug report, include:

- A clear title
- What you expected vs. what happened
- Steps to reproduce
- Your operating system and version
- Node.js version
- Which model/provider was involved
- Relevant screenshots, logs, or error messages

## Pull request process

1. Create a feature branch from `main`.
2. Make your change in a focused commit or commits.
3. Open a pull request with a clear explanation of the problem and solution.
4. Link any related issue if applicable.

## Security

Please do not disclose security vulnerabilities in public issues. Use the private security reporting link instead.

Thank you for helping improve Roundtable.
